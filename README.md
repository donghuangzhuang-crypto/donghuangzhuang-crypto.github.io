# Donghuang · DH — Personal Website

English · [简体中文](README.zh-CN.md)

A bilingual portfolio of tools and projects in content creation, creator marketing, market research, and learning.

## Preview and update

Open `index.html` for a local preview. For the same URL behavior as GitHub Pages, run `python3 -m http.server 8080` and visit `http://localhost:8080`.

1. Edit the Chinese and English project copy in `projects.json`.
2. Run `python3 build.py` to regenerate both pages.
3. In GitHub Desktop, review the diff, commit, and push `main`.

On GitHub Pages, set the source to **Deploy from a branch**, with **main / (root)**. The website is static and requires no live application services.
