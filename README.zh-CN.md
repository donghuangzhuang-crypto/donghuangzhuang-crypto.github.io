# 东煌 DH · 个人官网

简体中文 · [English](README.md)

中英文作品集，收录内容创作、出海与红人营销、市场投研及学习工具。

## 本地预览与更新

可直接打开 `index.html`。若需验证 GitHub Pages 上的路径行为，运行 `python3 -m http.server 8080`，访问 `http://localhost:8080`。

1. 在 `projects.json` 同时更新中文与英文简介。
2. 运行 `python3 build.py`，重建两种语言的页面。
3. 用 GitHub Desktop 查看变更，提交并推送到 `main`。

GitHub 的 **Settings → Pages** 选择 **Deploy from a branch**，来源设为 **main / (root)**。站点本身是静态网页。
